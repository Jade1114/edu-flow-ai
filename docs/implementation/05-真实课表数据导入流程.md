# 真实课表数据导入流程

> 更新时间：2026-05-31
> 范围：从全校课表 XLS 文件到 MySQL 数据库的完整数据管道。

---

## 概述

学校教务系统导出的全校班级课表（XLS 格式）→ 批量解析 → 结构化 JSONL → 导入 MySQL。

适用于：论文实验数据准备、消融实验基准、对比真实课表。

---

## 数据来源

- 路径：`~/Downloads/2025-2026学年1学期总课表/`
- 格式：每个班级一个 `.xls` 文件，文件名格式 `{年级}级{专业}{班号}班课表_{时间戳}.xls`
- 总数：499 个班级，覆盖全校所有院系

### 文件结构

每个 XLS 统一为 37 列 × 26 行的标准格式：

| 行 | 内容 |
|---|------|
| 0 | 标题（含院系、专业、班级、人数） |
| 2 | 星期表头（周一~周日 × 5 个节次组） |
| 3 | 节次子表头（12, 34, 56, 78, 91011） |
| 4-23 | 第 1~20 周课程安排 |
| 24 | 课程汇总（课程名、代码、学分、学时、教师、教室） |

每个排课单元格格式：`课程代码\n教室代码`（如 `软184\n93106`）。

## 处理流程

### 第一步：解析 → JSONL

```
scripts/parse_timetables.py
```

输入：499 个 `.xls` 文件
输出：`data/real-dataset/` 下的结构化数据

| 文件 | 格式 | 内容 | 规模 |
|------|------|------|------|
| `teachers.jsonl` | JSONL | 教师（含归属院系） | 624 人 |
| `courses.jsonl` | JSONL | 课程（含代码、学分、学时） | 704 门 |
| `classrooms.jsonl` | JSONL | 教室（含楼栋、类型） | 408 间 |
| `class_groups.jsonl` | JSONL | 班级（含年级、专业、人数） | 499 个 |
| `teaching_tasks.jsonl` | JSONL | 教学任务（课程×教师×班级） | 4,308 条 |
| `timetables.jsonl` | JSONL | 真实排课（周×天×节次×教室） | 87,536 条 |
| `summary.csv` | CSV | 汇总统计 | 499 行 |

### 第二步：推断课程类型

从 `timetables.jsonl` 的排课记录分析每门课实际使用什么类型的教室：

- 只用普通教室 → **理论课**
- 只用机房 → **上机实践**
- 两者都用 → **理论+上机**
- 虚拟教室 → **网络课程**

结果更新到 `course.course_type` 和 `course.required_room_type`。

### 第三步：推断教室信息

从教室编号推断：

- 编号前缀规则：
  - `0` 开头 → **1号楼**（普通教室）
  - `9` 开头 → **2号楼**（机房）
  - `虚拟` → **虚拟教室**
  - `操场` → **室外**
- 类型从排课记录中实际使用情况推断

### 第四步：导入 MySQL

```
scripts/import_to_db.py [--truncate]
```

读取 JSONL 文件 → INSERT 到 `edu_flow_ai` 数据库：

| 表 | 来源 | 关键字段 |
|----|------|---------|
| `teacher` | teachers.jsonl | employee_no(自动生成), name, department |
| `course` | courses.jsonl | name, code, credits, course_type |
| `classroom` | classrooms.jsonl | name, building, classroom_type |
| `class_group` | class_groups.jsonl | name, major, grade, student_count |
| `time_slot` | 自动生成 | 20周×5天×5节次 = 500条 |
| `teaching_task` | teaching_tasks.jsonl | course_id, teacher_id, total_hours |
| `teaching_task_class_group` | teaching_tasks.jsonl | teaching_task_id, class_group_id |

支持 `page=-1` 参数获取全量数据（用于下拉框），`page=0&size=20` 获取分页数据（用于表格）。

## 教学任务创建

在前端"基础数据管理 → 教学任务"中创建任务时，支持四种课程类型：

| 类型 | 行为 | 教室类型 |
|------|------|---------|
| 理论课 | 创建 1 条教学任务 | 普通教室 |
| 上机实践 | 创建 1 条教学任务 | 机房 |
| 理论+上机 | **创建 2 条关联任务** | 普通教室 + 机房 |
| 体育 | 创建 1 条教学任务 | 操场 |

`理论+上机` 自动拆分为两条教学任务，通过 `notes` 中的 `pair:{id}` 关联。
