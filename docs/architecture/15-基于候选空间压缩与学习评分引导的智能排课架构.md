# 基于候选空间压缩与学习评分引导的高校智能排课架构

> **V2 核心架构 · 2026-05-31**
> 
> 本架构取代此前所有架构设计文档（14-双通道、13-评分体系等仅作历史参考）。
>
> **核心变化：LightGBM 不再只是方案终点的评分器，而是嵌入排课构造过程的每一步，引导候选选择。**

---

## 一句话定义

> **规则负责保证不冲突，模型负责决定「哪个可行位置更符合教务偏好」。**

## 模块职责

| 模块 | 输入 | 输出 | 角色 |
|------|------|------|------|
| **教师交叉度分析** | 教学任务列表 | 高/低交叉分层 | 分治基础 |
| **任务优先级排序** | 分层结果 | 排课顺序队列 | 全局瓶颈控制 |
| **Template Generator** | Task + 预制模板库 | TopK 模板 | 时间候选压缩 |
| **Room Ranker (LightGBM)** | Task + 教室库 | TopK 教室 | 空间候选压缩 |
| **Slot Candidate Builder** | 模板 + 教室 | 可用 slot 集合 | 联合候选生成 |
| **硬约束过滤器** | 候选 + 已排课表 | 合法候选 | 可行性保证 |
| **Placement Scorer (LightGBM)** | 合法候选 | 评分排序 | 逐步引导 |
| **Beam Search 构造器** | 排序候选 | 初始课表 | 可控搜索 |
| **冲突检测器** | 合并课表 | 冲突列表 | 质量检查 |
| **冲突图构建** | 冲突列表 | 冲突簇 | 问题定位 |
| **局部修复引擎** | 冲突簇 | 修复课表 | 尾部收口 |
| **方案综合评价** | 多方案 | TopK | 最终选优 |
| **人工调课** | 选优方案 | 最终课表 | 兜底 |
| **反馈数据集** | 调课记录 | 训练样本 | 闭环 |

## 与旧架构的根本区别

| 维度 | 旧架构 (v1) | 新架构 (v2) |
|------|------------|------------|
| GA 的角色 | 核心构造引擎 | 局部修复工具 |
| LightGBM 角色 | 终点评分器 | 构造过程中每一步的引导器 |
| 搜索方式 | GA 全局搜索 | Beam Search 可控搜索 |
| 候选处理 | 全量候选 → GA 搜索 | 预压缩(TopK) → 过滤 → 评分 → 构造 |
| ML 介入时机 | 方案生成后 | 每一步决策中 |
| 可解释性 | 低（GA 黑盒） | 中（每步可见评分） |
| 效率 | O(全量×GA迭代) | O(TopK×N) |
| 创新定位 | GA + 终点评分 | 候选空间压缩 + 学习评分引导 |

## 论文答辩口径

**如果导师问：「你的系统和传统 GA 排课有什么区别？」**

> 本系统采用「候选空间压缩 + 分阶段构造 + 智能评价」的架构。
> 首先利用预制模板和 LightGBM 排序模型分别缩小时间模板与教室候选空间；
> 随后采用教师交叉度分层策略生成全校可行课表；
> 最后结合教师画像与 LightGBM 对候选课表进行质量评价与选优，
> 实现大规模高校排课的高效生成与个性化优化。
