# 03-排课方案生成总链路

> 2026-05-16 定稿，反映当前链路与目标链路之间的差异。

---

## 概述

排课方案生成链路是 edu-flow-ai 的核心流程。教务创建排课任务、绑定教学任务后，系统自动生成多套候选方案，经由规则检测、策略评估、画像匹配后提交教务确认。

## 三层评分架构

排课方案生成阶段（④）的候选评分由三层叠加：

```
单候选得分 = LightGBM模型分（①）
           + 策略权重调整（②）  ← 教务意志，页面可调
           - 教师画像惩罚（③）  ← 个体偏好，画像驱动
           + 教室粘性奖励        ← 软约束
           + 随机扰动            ← 打破重复
```

| 层 | 驱动者 | 可调节方式 | 需要重训模型 |
|---|--------|-----------|:--:|
| LightGBM 模型 | 历史模式 | 重训 | 是 |
| 10 个策略权重 | 教务 | 页面选/LLM翻译/手动改 | 否 |
| 教师画像惩罚 | 教师个人 | 修改画像文本 | 否 |

---

## 关键设计决策

1. **LLM 不参与排课决策**——只负责翻译人类语言为结构化参数（②③）
2. **LightGBM 做核心决策**——每步选择由模型主导，规则兜底
3. **画像不进模型**——个体偏好通过软惩罚层动态生效，改了画像不用重训
4. **策略权重全局统一**——10 个参数管所有人，个体差异由画像层处理
