# 当前进度

## 已完成

- `teacher` 表增加 `employee_no`、`password`、`role` 登录字段，`employee_no` 唯一。
- 教师 CRUD 已带上工号、密码、角色字段；创建教师要求工号和密码，更新教师时未传密码会保留原密码。
- 种子数据增加一个 `ADMIN` 演示账号和多名 `TEACHER` 演示账号，演示密码统一为 `123456`。
- 新增 `POST /api/auth/login` 简化登录接口，基于 teacher 表校验工号、明文密码和 `ACTIVE` 状态。
- 查看页增加“登录测试”区域，可直接调用登录接口并展示返回结果。
- 新增 `AuthService` 单元测试，覆盖登录成功、密码错误、非 `ACTIVE` 禁止登录。

## 后续可替换项

- 明文密码改为哈希存储和校验。
- 简化登录改为 Spring Security 或其他认证框架。
- 如果后续账号类型变复杂，可将登录主体从 `teacher` 表拆到独立用户表。
