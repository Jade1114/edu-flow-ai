# 训练样本收集优先路线

## 背景判断

当前阶段暂缓实现模型重训。真实样本量还不足，直接做重训很难稳定体现效果，也容易把主要精力消耗在流程完整性而不是模型可验证性上。

下一阶段优先目标是让系统可靠地产生可训练数据：先把方案选择、手动调整、冲突变化、画像扣分变化等行为沉淀成结构化样本，再基于样本覆盖情况决定何时进入重训。

## 优先建设内容

1. 方案级反馈样本
   - 记录用户确认的候选方案。
   - 记录同一任务下未被选择或被拒绝的候选方案。
   - 保存确认前后的方案评分、冲突数、画像扣分、班级均衡等快照。
   - 记录确认前发生过多少次手动调整。

2. 片段级调整样本
   - 记录片段从哪个时间/教室移动到哪个时间/教室。
   - 记录移动前后冲突状态变化。
   - 记录移动前后教师画像扣分变化。
   - 记录移动前后方案综合评分变化。
   - 支持用户填写调整原因，也保留系统推断原因。

3. 负样本沉淀
   - 未被选择的候选方案。
   - 用户手动移走的位置。
   - 触发硬冲突的位置。
   - 命中教师画像惩罚的位置。

4. 样本快照
   - 每条样本保存当时的教师画像摘要、教学任务、教室、时间片、方案评分摘要和冲突摘要。
   - 避免后续基础数据变化后，只凭 ID 无法还原当时训练语境。

5. 样本看板
   - 展示方案级样本量、片段级调整样本量。
   - 展示正负样本比例。
   - 展示教师、班级、课程覆盖情况。
   - 区分真实确认样本和测试调整样本。

## 后续进入重训的条件

- 有足够数量的真实确认方案和手动调整记录。
- 正负样本比例不极端失衡。
- 教师、班级、课程覆盖面能够支撑对比评估。
- 能用固定验证集观察到模型排序或片段推荐质量变化。

在这些条件满足前，模型训练模块以样本采集、样本查询、样本质量检查为主。
