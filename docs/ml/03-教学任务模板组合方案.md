# 教学任务模板组合方案

> 日期：2026-05-23
> 状态：设计完成，待实现

## 问题

当前 GA 在 `[1×18, 6零散]` 固定拆分下，每个 `(week, day, period, classroom)` 仍是独立基因。同一教学任务在不同周之间缺少模板约束，导致每周课表布局随机变化，不符合人工排课的稳定性习惯。

## 核心思路

将排课从"每个时间片独立搜索"重构为「**教学任务 → 模板 → 方案**」三层：

```text
教学任务
    ↓
  枚举所有合法的模板组合（覆盖总课时）
    ↓
  GA 为每个任务选一个模板组合
    ↓
  按周展开，检测 slot 冲突
    ↓
  方案
```

### 模板定义

一个模板 = 一段固定的排课节奏：

```
模板 = (每周节数, day, period, classroom, 持续周数)
```

多个模板可以并行组合，覆盖一个教学任务的总课时：

```
教学任务A × 24 periods

模板组合候选：
  ┌──────────────────────────────────────────┐
  │ 方案1: [2节/周 × 12周]                   │
  │        → 每周2节 @ 周一3-4节，持续12周    │
  │        = 24 periods ✓                     │
  ├──────────────────────────────────────────┤
  │ 方案2: [2节/周 × 6周, 1节/周 × 12周]     │
  │        → 2节/周 @ 周一3-4节，持续6周      │
  │        + 1节/周 @ 周三5节，持续12周       │
  │        = 12+12 = 24 periods ✓            │
  ├──────────────────────────────────────────┤
  │ 方案3: [3节/周 × 8周]                    │
  │        → 每周3节 @ 周一2-4节，持续8周     │
  │        = 24 periods ✓                     │
  ├──────────────────────────────────────────┤
  │ 方案4: [1节/周 × 18周 + 6节零散]         │
  │        → 1节/周 @ 周一3节，持续18周       │
  │        + 6 个零散 (week, day, period)     │
  │        = 18+6 = 24 periods ✓             │
  └──────────────────────────────────────────┘
```

每个模板组合内部的 `(day, period, classroom)` 尚未填充——这是 GA 要搜的内容。模板组合只定义了**结构骨架**（分几段，每段每周几节，持续几周）。

### 方案构成

```
方案 = {
  教学任务A: 模板组合2 (骨架 + day/period/classroom),
  教学任务B: 模板组合1 (骨架 + day/period/classroom),
  教学任务C: 模板组合4 (骨架 + day/period/classroom + 零散填充),
  ...
}
```

按周展开后，同一 `(week, day, period)` 不能被两个任务同时占用。

## 模板枚举规则

### 输入

- `total_hours`：教学任务总课时
- `periods_needed = total_hours / 2`：需要排的节次数（每课时=2节，此处节指 45min 一节）
- `total_weeks`：学期总周数（当前 18 周）

### 约束

1. 所有模板段的 `(每周节数 × 持续周数)` 之和 = `periods_needed`
2. 每个模板段的 `持续周数 ≥ 1` 且 `≤ total_weeks`
3. 每个模板段的 `每周节数 ≥ 1`
4. 所有并行模板段的总"每周节数"之和 ≤ 每日最大节数 × 每周可排天数（合理上限，不硬卡）
5. 零散段：持续 1 周的模板视为零散片段，允许多个零散段存在

### 枚举策略

对 `periods_needed` 进行整数拆分，每组拆分的每个元素再分配持续周数：

```python
def enumerate_templates(periods_needed, total_weeks=18):
    """
    枚举所有合法的模板组合骨架。
    
    返回: [
        {"segments": [{"weekly": 2, "weeks": 12}], "score": None},
        {"segments": [{"weekly": 2, "weeks": 6}, {"weekly": 1, "weeks": 12}], "score": None},
        ...
    ]
    其中 template_segments 是骨架，week=6 的段比 week=12 的段在物理上更靠前？
    """

    约束:
    - 2×12 可以
    - 2×6 + 1×12 可以 (先排密再排疏 或 穿插排)
    - 1×18 + 零散1×6 可以
    - 3×8 可以
    - 零散片段(=1周) 一共不超过 N 个（比如6）
    - 不允许: 某个段的 weekly=0 ❌
```

#### 周排序规则

当模板组合包含多个段时，这些段的周不重叠，按以下规则填充日历：

- 段的物理排列按 `weekly` 从大到小排序（先密后疏），更符合实际教学节奏
- 同 `weekly` 的段按原始枚举顺序排列
- 例如 `[2×6, 1×12]` → 前 6 周每周 2 节，后 12 周每周 1 节

#### 对零散片段的处理

- `每周节数 × 持续周数 < periods_needed` 的部分以零散片段补齐
- 零散片段本质上就是当前版本的独立基因，但数量大幅减少
- 零散片段只作为"实在凑不齐整数段"的补丁

## GA 建模变更

### 个体结构

```
individual = {
  task_id_1: {
    template_index: 2,                         # 选第几个模板组合骨架
    segments: [
      {day: 1, period: 3, classroom: 101},     # 段1 的填充
      {day: 3, period: 5, classroom: 102},     # 段2 的填充
    ],
    scattered: [
      {week: 3, day: 2, period: 1, classroom: 101},  # 零散片段的填充
      {week: 10, day: 4, period: 2, classroom: 103},
    ]
  },
  task_id_2: { ... },
  ...
}
```

### 个体长度对比

| 场景 | 当前 GA | 模板组合 GA |
|------|---------|------------|
| 8 个任务 × 混合课时 | 170+ 基因 | ~8 基因(任务数) + 每个任务内部几段 |
| 10 个任务 | 200+ | ~10-30 基因 |

### 交叉操作

不再是基因级别的交叉，而是**模板组合级别的交叉**：

- 两个父个体交换某个教学任务选的模板组合
- 也可以交换某个任务内部某个段的 `(day, period, classroom)`

### 变异操作

- 重新选一个模板组合骨架（跳转到另一个结构）
- 微调某段的 `(day, period, classroom)`
- 交换两个段的 `day` 或 `period`

### 适应度评估

1. **展开**：每个任务按所选模板组合展开为所有周的 assignment
2. **冲突检测**：统计所有任务间的 `(week, day, period)` 冲突
3. **完整性检测**：所有任务的 periods 总和是否正好覆盖
4. **软评分**：教师画像、分布均衡、教室粘性等（与当前一致）
5. **模板内稳定性奖励**：同一个模板段内周与周之间稳定性已由模板保证，无需额外奖励

## 输出契约

保持与现有 Java 解析兼容的输出格式：

```text
ml/data/generated/task_<taskId>_<runId>/
├── scheme_001.csv           # 含所有周的所有 assignment
├── summary.csv              # 方案级摘要
├── teacher_penalties.json   # 教师画像扣分
├── ga_summary.json          # GA 参数与适应度
└── template_debug.json      # 新增：每个任务选的模板组合详情
  # 格式: {
  #   "task_<id>": {
  #     "template": {"segments": [...], "scattered": [...]},
  #     "expanded_weeks": [1, 3, 5, ...],
  #     "total_periods": 24
  #   }
  # }
```

### `template_debug.json` 说明

新增调试输出，记录每个教学任务实际使用的模板组合，便于排查和前端展示：

```json
{
  "task_101": {
    "template_index": 2,
    "total_periods": 24,
    "segments": [
      {"weekly_count": 2, "weeks": 6, "day": 1, "period": 3, "classroom_id": 101},
      {"weekly_count": 1, "weeks": 12, "day": 3, "period": 5, "classroom_id": 102}
    ],
    "scattered_slots": []
  }
}
```
