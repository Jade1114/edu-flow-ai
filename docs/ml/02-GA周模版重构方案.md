# GA 周模版重构方案

日期：2026-05-23
状态：已实现

## 实现概要

GA 周模版重构已完成并合并入主生成链路，改动涉及 `ml/scheduling/ga/` 下的核心引擎模块：

- 候选池构建（`candidates.py`）：拆分为模版候选池和零散候选池两套构建逻辑
- 个体构造与展开（`pipeline.py`）：模版基因 `(day, period, classroom)` 绑定后自动复制到学期所有周
- 遗传算子（`ga_operators.py`）：模版段和零散段独立交叉，不混合
- 适应度评估（`fitness.py`）：展开后的 assignment 进行统一冲突检测与评分
- 每周固定 N 节模版，课时排完即止，`base_weekly=0` 的任务回退为零散片段模式

GA 参数支持环境变量选档（`ML_GA_PROFILE=fast/default/quality`），并输出诊断日志。

## 动机

当前 GA 把教学任务的每个片段（fragment）视为完全独立的基因，导致：

- 同一任务在不同周可能排到不同时间、不同教室，不符合人工排课习惯
- 个体长度大（170+ 基因），搜索空间过大
- week 1 天然没有被填充的激励（见输出日志：方案周分布缺失 week 1）

## 核心思路：周模版 + 零散补丁

每个教学任务计算「每周固定 slot」，选定 `(day, period, classroom)` 后自动复制到学期所有周。
剩余零头课时作为独立片段灵活分配。

### 拆分规则

```
periods_needed = total_hours // 2
base_weekly = periods_needed // 18（学期总周数）
extra_fragments = periods_needed % 18
```

示例：

| total_hours | periods_needed | base_weekly | extra_fragments |
|-------------|---------------|-------------|-----------------|
| 48 | 24 | 1 | 6 |
| 36 | 18 | 1 | 0 |
| 72 | 36 | 2 | 0 |
| 18 | 9 | 0 | 9 |

`base_weekly=0` 的任务全部走零散片段模式（退化为当前 GA）。

## 候选池

### 模版候选池

1. 和现在一样，在所有 time_slot × classroom 上构建候选行
2. LightGBM 打分
3. 按 `(day_of_week, period_index, candidate_classroom_id)` 去重，保留最高分
4. 按 score 排序，取 top N（默认 30）

候选 = `(day, period, classroom)` — 不绑定具体周。

### 零散候选池

同当前 GA 逻辑：候选 = `(week, day, period, classroom)`，取 top 40。

## GA 个体结构

```
individual = [
  template_genes:
    task1_slot0, task1_slot1, ...,
    taskN_slot(base_weekly-1),
  flexible_genes:
    task1_extra0, task1_extra1, ...,
    taskN_extra(extra-1),
]
```

- 模版基因：选 `(day, period, classroom)`，展开后覆盖所有周
- 零散基因：选 `(week, day, period, classroom)`，只放指定周

### 个体长度对比

| 场景 | 当前 | 模版模式 |
|------|------|---------|
| 8 任务 × 48h | 192 基因 | ~30 基因 |
| 8 任务 × 混合 | 170+ | ~35 |

## 展开与评估

1. 展开：每个模版基因 → 复制到 week 1~18，生成 18 条 assignment
2. 合并零散基因的 assignment
3. 冲突检测、适应度计算与当前一致

```
总 assignment 数 = (template_slots × 18) + extra_fragments
```

## 遗传算子

### crossover

模版段和零散段独立交叉，不混合。两个亲本交换各自模版段再交换各自零散段。

### mutate

- 模版基因 mutate → 替换 (day, period, classroom)，影响该任务所有 18 周
- 零散基因 mutate → 和当前一样替换一个片段

### repair

模版展开后冲突可能更频繁（一个基因影响 18 周）。
Repair 需要快速找到不冲突的替代 (day, period, classroom)。

## 特殊场景处理

### 场景一：串行排课（任务 A 上 1-9 周，任务 B 上 10-18 周）

当前阶段：不做显式周段设计。串行任务拆分为两个教学任务，通过教师工作量约束自然分离。

远期：教学任务增加 `start_week` / `end_week` 字段后，模版计算自动兼容：
`base_weekly = periods_needed // (end_week - start_week + 1)`

### 场景二：base_weekly=0 的任务（短课时）

全部回退到零散片段模式，与当前 GA 逻辑一致。

### 场景三：交叉授课、单双周交替

当前：不处理。用零散片段模拟。远期考虑 `repeat_pattern`（全周/单周/双周/自定义）配置。

## 实际实现关键参数

### GA 参数配置方式

GA 参数通过环境变量选档或单项覆盖：

| 配置方式 | 说明 |
|---|---|
| `ML_GA_PROFILE=fast` | 快速预览：candidate_top_n=40, population=60, generations=60 |
| `ML_GA_PROFILE=default` | 日常默认：candidate_top_n=60, population=100, generations=100 |
| `ML_GA_PROFILE=quality` | 最终排课：candidate_top_n=100, population=160, generations=200 |
| `ML_GA_CANDIDATE_POOL_SIZE=500` | 单项覆盖候选池上限 |
| `ML_GA_CANDIDATE_TOP_N=60` | 单项覆盖每片段候选数 |
| `ML_GA_POPULATION_SIZE=100` | 单项覆盖种群规模 |
| `ML_GA_GENERATIONS=100` | 单项覆盖迭代代数 |
| `ML_GA_ELITE_SIZE=10` | 单项覆盖精英保留数 |
| `ML_GA_TOURNAMENT_SIZE=5` | 单项覆盖锦标赛规模 |
| `ML_GA_MUTATION_RATE=0.10` | 单项覆盖变异概率 |

### 模版候选池参数

| 参数 | 默认值 | 说明 |
|---|---|---|
| 模版候选 top_n | 30 | `(day, period, classroom)` 去重后取 top |
| 零散候选 top_n | 40 | 同原逻辑 `(week, day, period, classroom)` |
